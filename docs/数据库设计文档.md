---

## 1. 概述

| 项 | 值 |
|---|---|
| 数据库 | MySQL 5.6.46（本机），库名 `online_exam` |
| 字符集 | `utf8`（5.6 不支持完整 utf8mb4，见第 2 节） |
| ORM | Django 4.2，主键统一 `BigAutoField` |
| 业务表 | **15 张**（不含 Django 自带的 auth/session/migrations） |
| 命名 | 全部使用 Django 默认表名 `<app>_<model>` |

### 1.1 MySQL 5.6 的三条硬约束（写新表时必须遵守）

1. **没有原生 JSON 字段** → 结构化小数据一律 `TextField` 存 JSON 字符串
   （如 `StudentAnalysisReport.payload`、`ExamBehaviorLog.detail`）；
2. `utf8mb4` 支持不完整 → 全库用 `utf8`；
3. Django 4.2 官方不支持 5.6 → 靠 `DB_SKIP_VERSION_CHECK=True` 跳过版本校验。
   升级到 MySQL 8.0 后可去掉这两行兼容配置。

### 1.2 通用约定

- 所有业务表都有 `created_at` / `updated_at`（`auto_now_add` / `auto_now`）；
- 删除策略分两种：**软删除**（题目、知识点用 `is_active=False`）
  与**硬删除**（试卷，无历史引用风险者）；考试有作答记录时**只能归档不能删**；
- 冗余汇总字段（`Paper.total_score` 等）由 Service 的 `recalc()` 维护，**不要手工改**。

## 3. 逐表字段说明

### 3.1 `users_user`（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BigAutoField PK | |
| `username` / `email` / `student_no` | CharField | 三者都可作登录账号 |
| `password` | CharField | 哈希，不明文 |
| `role` | CharField | `admin` / `teacher` / `student` |
| `real_name` / `phone` / `school` | CharField | 资料 |
| `avatar` | FileField (null) | 头像（依赖 Pillow） |
| `is_active` / `is_staff` / `is_superuser` | Boolean | Django 标准 |
| `last_login_ip` | GenericIPAddress (null) | |
| `date_joined` / `last_login` | DateTime | |

索引：`(role, is_active)`、`(-date_joined)`；排序 `-date_joined`。

### 3.2 `ai_airequestlog`（AI 调用日志）

`provider` / `model` / `scene` / `user`(FK null) / `success` / `is_mock` /
`prompt_tokens` / `completion_tokens` / `total_tokens` / `latency_ms` /
`error`(Text) / `request_preview` / `response_preview` / `created_at`。

索引：`(provider, scene)`、`(-created_at)`。用于用量统计与排障。

### 3.3 `questions_knowledgepoint`（知识点）

`name` / `code` / `subject` / `parent`(FK 自关联, null) / `description` /
`order` / `is_active` / `created_by`(FK User, null)。

索引：`(subject, parent)`、`(parent, order)`。删除规则：子树内还有在用题目则拒绝（12030），否则连带子节点物理删除（`parent` 为 CASCADE，所以校验必须覆盖整棵子树）。

### 3.4 `questions_question`（题目）

`type`（single/multiple/judge/fill/short/essay）/ `stem` / `difficulty`(1–4) /
`score`(Decimal) / `reference_answer` / `analysis` / `subject` /
`source`(manual/ai/import) / `ai_provider` / `ai_model` /
`created_by`(FK null) / `is_active` / `is_reviewed` / `usage_count` / `correct_count`。

索引：`(type, difficulty)`、`(is_active, type)`、`(subject, type)`、`(-created_at)`。
**删除为软删除**（`is_active=False`），保护历史试卷可追溯。

### 3.5 `questions_questionoption`（选项）

`question`(FK) / `label` / `content` / `is_correct` / `order`。排序 `(question, order, label)`。

### 3.6 `papers_paper`（试卷）

`title` / `subject` / `description` / `status`(draft/published/archived) /
`generation_mode`(manual/ai/random/hybrid) / `duration_minutes` / `total_score` / `pass_score` /
`question_count`（**冗余汇总，由 `recalc()` 维护**）/ `target_difficulty` /
`ai_notes` / `ai_provider` / `ai_model` / `created_by`(FK null) / `published_at`(null)。

### 3.7 `papers_papersection`（大题）

`paper`(FK) / `title` / `question_type` / `description` / `order` /
`score_per_question`(Decimal, null)。

### 3.8 `papers_paperquestion`（卷内题目）

`paper`(FK) / `section`(FK null) / `question`(FK) / `order` /
`score` / `question_type` / `difficulty`。

> 后三个是**快照**：题库改题不改历史卷面。索引 `(paper, order)`、`(section, order)`。

### 3.9 `exam_exam`（考试）

`title` / `description` / `subject` / `paper`(FK) /
`status`（**只存** draft/published/finished/archived，"进行中"按时间实时算）/ `start_time` /
`end_time` / `duration_minutes` / `pass_score`(null) / `max_attempts` /
`multiple_choice_policy`(strict/partial/penalty) / `shuffle_questions` / `shuffle_options` /
`detect_switch` / `max_switch_count` / `auto_submit_on_limit` / `detect_paste` /
`fullscreen_required` / `allow_resume` / `show_score_immediately` / `open_to_all` /
`created_by`(FK null) / `published_at`(null)。

### 3.10 `exam_examattempt`（作答记录）

`exam`(FK) / `student`(FK User) / `attempt_no` /
`status`（in_progress/submitted/auto_graded/reviewing/graded/timeout）/
`started_at` / `deadline_at`（**服务端权威**）/ `submitted_at`(null) / `graded_at`(null) /
`time_spent_seconds` / `total_score_snapshot` / `score` / `objective_score` /
`subjective_score` / `question_count` / `answered_count` /
`switch_count` / `paste_count` / `fullscreen_exit_count` / `heartbeat_count`（**聚合计数**）/
`last_heartbeat_at`(null) / `ip_address` / `user_agent` / `is_timeout` /
`submit_reason` / `shuffle_seed`（**确定性乱序种子**）。

索引：`(exam, status)`、`(student, -started_at)`。

### 3.11 `exam_answer`（逐题作答明细）

`attempt`(FK) / `paper_question`(FK) / `selected_labels`（客观题答案）/
`answer_text`（填空与主观题答案）/ `is_flagged` / `is_answered` /
`is_correct`(Boolean **null = 未判分**) / `score` / `ai_score`(null) /
`ai_comment` / `teacher_comment` / `time_spent_seconds` / `order`。

索引：`(attempt, is_answered)`、`(paper_question)`。
`is_correct` 用 `null` 区分"还没判"与"判错了"，模块五的待批队列靠它。

### 3.12 `grading_gradingfeedback`（复核审计）

`answer`(FK) / `attempt`(FK) / `reviewer`(FK User null) /
`question_type` / `source`(ai/teacher) / `action` /
`ai_score`(null) / `ai_ratio`(null) / `original_score` / `final_score` /
`delta` / `full_score` / `comment`。

索引：`(answer, -created_at)`、`(attempt, -created_at)`、`(reviewer, -created_at)`。

### 3.13 `analytics_studentanalysisreport`（AI 学情诊断缓存）

`student`(FK) / `scope_key` / `scope_display` / `subject` / `summary` /
`overall_level` / `weak_point_count` / `knowledge_point_count` / `sample_size` /
`payload`(Text，**JSON 字符串**) / `provider` / `model` / `is_mock` / `generated_at`。

索引：`(student, scope_key)`、`(-generated_at)`。
`update_or_create` 只覆盖不堆积；`is_stale(hours)` 判过期（TTL 24h）。

### 3.14 `proctoring_exambehaviorlog`（行为埋点）

`attempt`(FK) / `exam`(FK) / `student`(FK User) /
`event_type`（switch/paste/fullscreen_exit/blur/heartbeat）/
`count` / `occurred_at` / `duration_seconds` /
`question`(FK null) / `question_index` / `ip_address` / `user_agent` /
`detail`(Text，JSON 字符串)。

索引：`(attempt, -occurred_at)`、`(exam, event_type)`、`(exam, -occurred_at)`、
`(student, -occurred_at)`。排序 `-occurred_at`。

> **只存事实、不存结论**：「算不算可疑」由规则引擎读时现算，改阈值后历史结论不过时。

### 3.15 `classroom_classroom`（班级）

`name` / `grade_year` / `subject` / `description` /
`class_type`（admin 行政班 / subject 学科班）/ `admin_class`(FK self, null，学科班挂靠的行政班) /
`head_teacher`(FK User, null) / `created_by`(FK User, null) /
`is_active`（归档标记）/ `created_at` / `updated_at`。

多对多：`teachers`（授课教师，中间表 `classroom_teachers`）、
`students`（学生成员，中间表 `classroom_students`）。

索引：`(is_active, -created_at)`、`(name)`、`(class_type)`。

> **班级是系统里第一个真正的「班级」实体**：此前「班级成绩单」「班级维度」都是
> 「某场考试全部考生」的临时聚合。班级分**行政班**（学籍班）与**学科班**（按课程分的教学班），
> 学科班通过 `admin_class` 挂靠一个行政班；删除班级是物理删除（与考试/成绩无外键关联），
> 要「下线但保留」用 `is_active=False` 归档。

## 4. 索引设计原则

1. **按查询模式建**，不按字段建：列表页按 `(状态, -时间)`，详情页按外键；
2. 复合索引顺序 = 「等值过滤字段在前，排序字段在后」（如 `(exam, status)`、`(attempt, -occurred_at)`）；
3. 埋点表 4 个索引已经覆盖了「按作答 / 按考试 / 按学生 / 按时间」四种查法；
4. 不在低区分度字段上单独建索引（如 `is_active`）。

## 5. 数据量与保留策略

| 表 | 量级 | 策略 |
|---|---|---|
| `questions_question` | 701 道（演示库） | 软删除，不清 |
| `exam_answer` | 每次作答 × 题数 | 随考试归档保留 |
| `proctoring_exambehaviorlog` | **最大**（一场考试每生几十上百条） | 保留 180 天，`purge_behavior_logs` 裁剪 |
| `ai_airequestlog` | 每次 AI 调用 1 条 | 保留 180 天（同裁剪思路） |
| `analytics_studentanalysisreport` | 学生 × scope | 覆盖式，不堆积 |

```bash
# 先预览、再真删
python manage.py purge_behavior_logs --dry-run
python manage.py purge_behavior_logs --days 90
```

## 6. 迁移与维护

```bash
python manage.py makemigrations          # 生成
python manage.py migrate                 # 应用
python manage.py showmigrations          # 查看状态
python manage.py migrate <app> <编号>     # 回滚到指定迁移（谨慎）
```

迁移文件按 app 分目录存放（`apps/<app>/migrations/`）。
**MySQL 5.6 上不要跑会重建表的迁移**（如改字段类型），先备份。
