## 4. 性能测试用例

> ⚠️ **本机 `runserver` 是单线程**，压它只会测到它自己，数字没有参考价值。
> 性能压测必须起 **gunicorn**（多 worker）后再压，或在部署环境做。

### 4.1 场景一：并发交卷（写峰值）

- 目标：`POST /api/v1/attempts/{id}/submit/`
- 负载：50 / 100 / 200 并发持续 5 分钟
- 关注：平均响应时间、P95、错误率、数据库锁等待
- 通过线（建议）：P95 < 2s，错误率 < 1%

### 4.2 场景二：开考瞬间读峰值

- 目标：`POST /api/v1/exams/{id}/start/`（大批学生同时拉卷）
- 负载：100 并发在 10 秒内同时开考
- 关注：响应时间、是否有 N+1（看 SQL 日志条数）、缓存与连接池
- 通过线（建议）：P95 < 3s，不出现 5xx

### 4.3 Locust 脚本骨架

```python
# scripts/locustfile.py（示例，未纳入仓库）
from locust import HttpUser, task, between
import random


class StudentUser(HttpUser):
    wait_time = between(1, 3)

    def on_start(self):
        r = self.client.post("/api/v1/auth/login/",
                             json={"username": "student", "password": "Exam@123456"})
        self.token = r.json()["data"]["access"]
        self.client.headers.update({"Authorization": f"Bearer {self.token}"})

    @task(1)
    def start_exam(self):
```
